Your Chrome profiles

Pair a Chrome profile
  1. Download the Chrome extension and extract the ZIP.
  2. In your personal Chrome, open chrome://extensions, enable Developer mode, click Load unpacked, and choose the extracted agent-relay-chrome folder.
  3. Give the connection a name, generate a code below, then paste this app’s address and the code into the extension.
  4. Sign into your websites normally in Chrome. Enable the top-right switch in a chat only when you want to share your signed-in profile.

The extension requests Chrome’s debugger permission for a separate automation tab. It cannot be installed silently. Your existing tabs are not shared. Disabling access closes the automation tab, not your Chrome profile.

WORKSPACE SETTINGS

Environments

MCP connections

Only selected connections allowed for this chat’s company reach the worker. The environment and the connection must both allow that company. Changes apply on the next worker start.

Custom egress restrictions are not enforced by this backend. Configure the worker network externally; agent sandbox permissions remain separate.

Installed software

Bash script run on each worker start, before the agent launches. Only agent-readable variables are injected. Do not put secrets directly in the script; its files can be read by the agent.

Variables

Protected values are encrypted and are never injected into agents. Agent-readable variables are passed to tools and can be read by the AI. Local mode still shares the host filesystem—use isolated cloud workers for a strong secret boundary.
