    Pair a Chrome profile
    1. Download the Chrome extension and extract the ZIP.
    2. In your personal Chrome, open chrome://extensions, enable Developer mode, click Load unpacked, and choose the extracted agent-relay-chrome folder.
    3. Give the connection a name, generate a code below, then paste this app’s address and the code into the extension.
    4. Sign into your websites normally in Chrome. Enable the top-right switch in a chat only when you want to share your signed-in profile.

    The extension requests Chrome’s debugger permission for a separate automation tab. It cannot be installed silently. Your existing tabs are not shared. Disabling access closes the automation tab, not your Chrome profile.

    About accounts and access

    Google sign-in does not sign you in to Codex or Claude. Server logins are never imported. Choose one of your accounts per chat. Your last choice is remembered for each primary repository; other users cannot use your accounts.

    WORKSPACE SETTINGS

    Environments

    One company per environment. Changing this assignment does not move chats or grant access to chats from another company. Running workers are not restarted.

    This environment needs a company assignment before it can start a worker. Saved variables remain unchanged. Choose one registered company explicitly.

    Access and advanced settings

    Company tools

    Tools follow the chat’s company automatically.

    CI monitoring defaults

    Applied when this environment starts following a new pull request. Each PR can still be changed from its CI menu.

    Network access uses the worker infrastructure default. Custom egress restrictions are not enforced here.

    Bash script run on each worker start, before the agent launches. Only agent-readable variables are injected. Do not put secrets directly in the script; its files can be read by the agent.

    Variables

    Protected values are encrypted and are never injected into agents. A protected NODE_AUTH_TOKEN is used only by Relay's read-only npm gateway; the agent receives a revocable capability, never the registry token. Agent-readable variables are passed to tools and can be read by the AI. Local mode still shares the host filesystem—use isolated cloud workers for a strong secret boundary.
